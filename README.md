# internet-speedtest

Консольный скрипт на Node.js: оценивает скорость скачивания, последовательно обращаясь к указанному URL.

Сделан как тестовое задание для вакансии Fullstack-разработчика (Python / Node.js) в «Это Легко».

## Что делает

1. Принимает URL (например, адрес тяжёлой картинки).
2. Делает **10 последовательных** запросов и каждый раз дожидается полного тела ответа.
3. Считает среднее время запроса и суммарный объём скачанных данных.
4. Печатает скорость скачивания в **Мбит/с** и **МБ/с**.

Зависимостей нет: используются только встроенные модули `node:http`, `node:https` и `node:perf_hooks`. Нужен Node.js 18 или новее.

## Как запустить

```bash
node speedtest.js <url>
```

Количество запросов по умолчанию — 10. Его можно переопределить вторым аргументом или переменной окружения `REQUESTS`:

```bash
node speedtest.js https://httpbin.org/image/jpeg 5
REQUESTS=20 node speedtest.js https://httpbin.org/image/jpeg
```

Через npm:

```bash
npm start -- https://httpbin.org/image/jpeg
```

## Единицы измерения

Используются десятичные (СИ) единицы, как принято для сетевых скоростей:

- 1 МБ = 1 000 000 байт
- 1 Мбит/с = 1 000 000 бит в секунду
- 1 МБ/с = 8 Мбит/с

**Скорость** считается как «суммарный объём / сумма времён всех запросов».
Это чистое время передачи, без пауз между запросами.

Время каждого запроса — от старта HTTP-запроса до полного получения тела ответа (`performance.now()`).

## Ограничения и допущения

- Поддерживаются только протоколы `http` и `https`.
- Редиректы `301`, `302`, `303`, `307`, `308` обрабатываются (до 5 штук, в том числе относительный `Location`). Время редиректа в замер финального ответа не входит.
- Любой ответ вне диапазона 2xx — ошибка, скрипт останавливается.
- Таймаут одного запроса — 30 секунд.
- Скрипт не распараллеливает запросы: это требование задания.
- На итоговую скорость влияют размер файла, сеть и то, прогрелся ли уже TCP/TLS. Для наглядного замера лучше брать достаточно большой файл.
